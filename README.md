**Vector fengshui-bazi** — навык (Agent Skill, открытый стандарт
[agentskills.io](https://agentskills.io)) для ИИ-ассистентов: Claude Code,
Codex CLI и ещё 30+ агентов, поддерживающих стандарт. Объединяет четыре
традиционные системы в одном рабочем процессе:

| Модуль | Что считает | Что интерпретирует модель |
|---|---|---|
| **八字 Бацзы** | 4 столпа (год по 立春, месяц по 12 节, день `(JDN+49)%60`, час), скрытые стволы, 十神, найнь, старт 大运 | сила дневного господина, 用神, разбор жизни по темам |
| **风水 Фэн-шуй** | карты 玄空飞星 (下卦), число гуа 八宅 и 8 направлений, годовые звёзды/духи 2026–2030 | 格局 (旺山旺向, 双星到向…), рекомендации по размещению, 煞 |
| **Нумерология** | жизненный путь, выражение/душа/личность (русский алфавит), личный год, психоматрица Пифагора | значения чисел, сочетание с бацзы |
| **姻缘 Супружество** | баллы 八字合婚 (веса yinyuan-skills), зодиакальные отношения 生肖， найнь-пары | категории «天作之合…不建议强求», зоны роста, 桃花 |

**Принцип: «Расчёт — коду, интерпретация — модели».** Арифметика 天干地支 —
главный источник правдоподобных ошибок ИИ, поэтому все числа выдаёт
детерминированный скрипт на чистой стандартной библиотеке Python 3.8+
(без pip-зависимостей), а модель отвечает за вопросы, разбор и стиль.

## Установка

### Как Agent Skill (рекомендуется)

```bash
npx skills add <ВАШ_НИК>/Vector-fengshui-bazi
```

или вручную — клонировать в каталог навыков вашего агента:

```bash
git clone https://github.com/<ВАШ_НИК>/Vector-fengshui-bazi ~/.agents/skills/vector-fengshui-bazi
# для Claude Code также подойдёт: ~/.claude/skills/vector-fengshui-bazi
```

### Требования

- Python 3.8+ (только стандартная библиотека, **ничего устанавливать не нужно**).

## Быстрый старт

```bash
cd ~/.agents/skills/vector-fengshui-bazi/scripts

# Четыре столпа (пример: 1990-05-15, 08:30, UTC+8, мужчина)
python3 fengshui_bazi_calc.py pillars --date 1990-05-15 --time 08:30 --gender m

# Число гуа и 4 счастливых направления
python3 fengshui_bazi_calc.py gua --date 1990-05-15 --gender m

# Карта летящих звёзд (фасад 187°, заселение в 2018, годовые звёзды 2026)
python3 fengshui_bazi_calc.py feixing --facing 187 --year 2018 --annual 2026

# Нумерология по дате рождения и имени
python3 fengshui_bazi_calc.py numerology --date 1990-05-15 --name "Иван Петров" --year-now 2026

# Совместимость пары (八字合婚)
python3 fengshui_bazi_calc.py match --d1 1990-05-15 --t1 08:30 --g1 m \
       --d2 1992-03-08 --t2 14:00 --g2 f

# Быстрая зодиакальная совместимость
python3 fengshui_bazi_calc.py zodiac --d1 1990-05-15 --d2 1992-03-08

# Регрессионные тесты по якорным датам
python3 test_anchors.py
```

Все команды поддерживают `--json`. Полное описание флагов — в
[SKILL.md](SKILL.md) (раздел 4).

## Калибры (школы) — объявляются в разборе

- год меняется по **立春** (~4 февраля), не по китайскому Новому году;
- месяц — по 12 **节** (точное солнечное время, точность ±15–20 минут);
- день по умолчанию меняется в **23:00**; флаг `--yeci` — школа «поздний цзы»
  (23:00–24:00 остаётся текущим днём);
- время рождения — местное, `--tz` задаёт пояс от UTC.

## Ограничения

- 择日 (выбор дат по 建除/黄黑道) не входит: используйте `lunar_python`
  или [voidforall/fengshui.skill](https://github.com/voidforall/fengshui.skill).
- 替卦 (отклонение фасада >3°) не считается — только базовые 下卦 карты.
- Даты до 1900 и после 2100 — за пределами гарантированной точности.
- 紫微斗数 / 奇门遁甲 доступны через
  [Numerologist_skills](https://github.com/FANzR-arch/Numerologist_skills).
