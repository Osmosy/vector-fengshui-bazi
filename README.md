Арифметика 天干地支 — главный источник правдоподобных ошибок ИИ: модель уверенно ставит не тот
столп дня, путает 六合 с 三合 или ошибается в годе по 立春. Этот навык снимает с модели счёт:
все числа выдаёт детерминированный скрипт на чистой стандартной библиотеке Python 3.8+, а модель
отвечает за маршрутизацию вопроса, разбор и стиль.

**Принцип: «Расчёт — коду, интерпретация — модели».**

| Модуль | Что считает код | Что остаётся модели |
|---|---|---|
| **八字 Бацзы** | 4 столпа (год по 立春, месяц по 12 节, день `(JDN+49)%60`, час), скрытые стволы, 十神, найнь, старт 大运 | сила дневного господина, 用神, разбор по темам |
| **風水 Фэн-шуй** | карты 玄空飞星 (下卦), число гуа 八宅 и 8 направлений, годовые звёзды и духи 2026–2030 | 格局 (旺山旺向, 双星到向…), размещение, 煞 |
| **Нумерология** | жизненный путь, выражение/душа/личность (русский алфавит), личный год, психоматрица Пифагора | значения чисел, сочетание с бацзы |
| **姻缘 Супружество** | баллы 八字合婚 (веса yinyuan-skills), зодиакальные отношения 生肖, найнь-пары | категории «天作之合…不建议强求», зоны роста, 桃花 |

## Быстрый старт

```bash
cd ~/.agents/skills/vector-fengshui-bazi/scripts

# Четыре столпа: 1977-09-23, 19:00, UTC+8
python3 fengshui_bazi_calc.py pillars --date 1977-09-23 --time 19:00

# Число гуа и восемь направлений (八宅)
python3 fengshui_bazi_calc.py gua --date 1984-06-01 --gender m

# Карта летящих звёзд: фасад 187°, заселение 2018, годовые звёзды 2026
python3 fengshui_bazi_calc.py feixing --facing 187 --year 2018 --annual 2026

# Нумерология по дате и имени
python3 fengshui_bazi_calc.py numerology --date 1990-05-15 --name "Иван Петров" --year-now 2026

# Совместимость пары (八字合婚)
python3 fengshui_bazi_calc.py match --d1 1990-05-15 --t1 08:30 --g1 m \
       --d2 1992-03-08 --t2 14:00 --g2 f

# Зодиакальная совместимость
python3 fengshui_bazi_calc.py zodiac --d1 1990-05-15 --d2 1992-03-08
```

## Калибры (школы) — объявляются в разборе

- год меняется по **立春** (~4 февраля), не по китайскому Новому году;
- месяц — по 12 **节**, точное солнечное время, точность формулы ±15–20 минут;
- день по умолчанию меняется в **23:00**; флаг `--yeci` — школа «поздний цзы»
  (23:00–24:00 остаётся текущим днём);
- время рождения местное, `--tz` задаёт пояс от UTC.

## Тесты

```bash
python3 scripts/test_anchors.py    # 34/34 проверок пройдено
```

Тесты держат якоря, на которых ломались реализации: 1990-05-15 = 庚辰-день, 1893-12-26 =
丁酉-день, 1977-09-23 19:00 (UTC+8) = 丁巳 己酉 癸未 壬戌, 1984 м → гуа 7, 1990 м → гуа 1,
плюс пары 六合/三合 и зодиакальные отношения. Таблица 六合 в первой версии содержала
перепутанные пары (子丑 0↔11, 午未 6↔1) — исправлено, отсюда и тесты.

## Ограничения

- 择日 (выбор дат по 建除/黄黑道) не входит: `lunar_python` или
  [voidforall/fengshui.skill](https://github.com/voidforall/fengshui.skill).
- 替卦 (отклонение фасада больше 3°) не считается — только базовые 下卦 карты.
- Даты до 1900 и после 2100 — за пределами гарантированной точности.
- 紫微斗数 и 奇門遁甲 — не в этом навыке.

Проект носит развлекательно-познавательный характер и служит для исследования традиционных
китайских практик. Ни бацзы, ни фэн-шуй, ни нумерология не заменяют медицину, психологию,
юриспруденцию и финансовые консультации. Карты и числа показывают структуру и склонности,
а не «приговор»: выбор и ответственность всегда за человеком.
