# Нумерология

Два слоя: (1) инженерная методология репозитория FANzR-arch/Numerologist_skills
(2143★) и его продвинутые движки; (2) классическая западная нумерология
(Пифагор), которую считает скрипт (`numerology`).

## 1. Методология Numerologist_skills (что принять как стиль работы)

Репозиторий не содержит «западной» нумерологии — это инженерный фреймворк
против галлюцинаций в Chinese astrology. Его принципы уже встроены в SKILL.md
(спрашивать → считать скриптом → объявлять калибр → показывать процесс).
Дополнительно из репозитория доступны **продвинутые движки** (если запрос
выходит за пределы этого навыка):

| Модуль | Что делает | Как запустить |
|---|---|---|
| `ziwei-doushu/` | 紫微斗数: 12 дворцов, 主星, 四化, 大限 | клонировать репо, `pip install lunar_python`, `python3 ziwei-doushu/scripts/ziwei_cli.py --input in.json --output out.json` |
| `qimen-dunjia/` | 奇门遁甲: выбор времени/направления под конкретное дело | клонировать репо, `pip install lunar_python tzdata`, `python3 qimen-dunjia/scripts/qimen_cli.py --input in.json --output out.json` |

Приоритет: если у пользователя уже есть готовый расчёт (скриншот/данные
другой программы) — сначала сверь калибр, потом интерпретируй его, а не пересчитывай.

## 2. Числа западной нумерологии (считает `numerology`)

Все числа сводятся суммой цифр; мастер-числа 11, 22, 33 в итоговых числах
НЕ сокращаются (в промежуточных — сокращаются).

| Число | Формула | О чём |
|---|---|---|
| Жизненный путь | сумма цифр полной даты рождения | главный урок/направление жизни |
| Выражение (судьба) | сумма значений букв полного имени | таланты, как реализоваться |
| Душа | сумма гласных имени | внутренние желания |
| Личность | сумма согласных имени | впечатление на других |
| Число дня рождения | день рождения (сокращённый) | дополнительный инструмент |
| Зрелости | жизненный путь + выражение (сокр.) | вторая половина жизни |
| Личный год | день + месяц рождения + цифры текущего года | тема года (1 старт…9 завершение) |

Значения чисел 1–9 (краткие):
1 — лидерство, самостоятельность; 2 — партнёрство, чуткость; 3 — творчество,
общение; 4 — порядок, труд, система; 5 — свобода, перемены, путешествия;
6 — забота, семья, ответственность; 7 — анализ, уединение, поиск смысла;
8 — управление, деньги, амбиции; 9 — служение, широта, завершение циклов.
11 — вдохновитель (интуиция + давление внимания); 22 — строитель больших
структур; 33 — учитель-целитель.

## 4. Психоматрица (квадрат Пифагора)

Скрипт строит её из цифр даты `ДД.ММ.ГГГГ` и четырёх «рабочих чисел»:
- n1 = сумма всех цифр даты;
- n2 = сумма цифр n1;
- n3 = n1 − 2 × первая цифра дня;
- n4 = сумма цифр n3.

Ячейка = сколько раз цифра встречается в дате + рабочих числах.

| Ячейка | Тема |
|---|---|
| 1 | Характер, воля |
| 2 | Энергия |
| 3 | Интерес к науке/творчеству |
| 4 | Здоровье, физика |
| 5 | Логика, интуиция |
| 6 | Труд, мастерство |
| 7 | Удача, «фарт» |
| 8 | Долг, доброта, чувство долга |
| 9 | Память, ум |

Трактовка: 0 ячеек — тема «в потенциале», 1–2 — умеренно, 3–4 — сильно,
5+ — перегруз/избыток. В ответе не ставить «диагнозы», говорить «склонности».

## 5. Совместимость по числам (для пар)

Считать жизненные пути обоих; ключевые сочетания:
- 1+1 — борьба за лидерство; 1+2 — классическая пара «ведущий-ведомый»;
  2+2 — взаимная чуткость, но риск нерешительности; 3+3 — весело, но без
  бытового фундамента; 4+4 — надёжно, риск рутины; 5+5 — свобода + свобода;
  6+6 — «семейный остров»; 7+7 — два одиночества; 8+8 — дела важнее чувств;
  9+9 — широкий круг интересов.
- Сумма партнёрских чисел 1 или 9 в парах 1+9, 2+7, 3+5, 4+6 — взаимодополняющие.
Полные выводы — по шаблону раздела «Супружество» (`references/supruzhestvo.md`).

## 6. Правила ответа

- Термины пояснять по-русски, без сектантского пафоса.
- Не выдавать «судьбоносность» чисел: это карта склонностей.
- Нумерологию имени можно комбинировать с бацзы: сначала числа, потом
  十神-портрет; расхождения честно помечать как разные системы (не смешивать).
