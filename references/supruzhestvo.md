# Супружество и совместимость (姻缘 · 合婚)

Источник метода: Ming-H/yinyuan-skills (639★): `references/bazi-matching.md`,
`zodiac-compatibility.md`, `ziwei-marriage.md`, `taohua-luck.md`.
Расчёт выполняют `match` и `zodiac` скрипта; интерпретация — по этому файлу.

**Главный принцип 月老**: «Развлечение в первую очередь, разумно для справки».
Не говорить о судьбе, не создавать тревожности; любой балл сопровождать
рекомендациями «как развивать отношения».

неполных данных — просто пометь точность.

## 2. Уровень 1: зодиакальная совместимость

Категории (ветви года): **六合** ⭐⭐⭐⭐⭐ 95; **三合** ⭐⭐⭐⭐ 85; **六害** 60;
**普通** — «нейтрально, зависит от усилий»; **六冲** 50 (не приговор!); **刑** —
частые трения; **破** — мелкие потеряшки.

| Союз/столкновение | Пары |
|---|---|
| 六合 | Крыса+Бык, Тигр+Свинья, Кролик+Собака, Дракон+Петух, Змея+Обезьяна, Лошадь+Коза |
| 三合 | Обезьяна-Крыса-Дракон; Тигр-Лошадь-Собака; Змея-Петух-Бык; Свинья-Кролик-Коза |
| 六冲 | Крыса-Лошадь, Бык-Коза, Тигр-Обезьяна, Кролик-Петух, Дракон-Собака, Змея-Свинья |
| 六害 | Крыса-Коза, Бык-Лошадь, Тигр-Змея, Кролик-Дракон, Обезьяна-Свинья, Петух-Собака |
| 刑 | Тигр-Змея-Обезьяна; Бык-Собака-Коза; Крыса-Кролик; самоповреждение Дракон/Лошадь/Петух/Свинья |
| 破 | Крыса-Петух, Лошадь-Кролик, Дракон-Бык, Змея-Обезьяна, Тигр-Свинья, Собака-Коза |

Правила интерпретации yinyuan: 六冲 ≠ «не быть вместе» — часто это «искры»;
если пара и 合 и 刑/破 — считай «минус к плюсу = нейтрально».
Для пары с 冲 предложить «посредника» — общего друга/партнёра из 三合-животного.

## 3. Уровень 2: 八字合婚 — балльная система (веса yinyuan-skills)

| Измерение | Вес | Что учитывает |
|---|---|---|
| Отношение стволов | 15% | 天干五合 (год/день) — притяжение; столкновения стволов — трение |
| Союзы ветвей | 20% | 六合/三合/三会 годовых и дневных ветвей |
| Столкновения ветвей | 15% | 六冲/六害/刑/破 — штрафной пункт |
| Дневной столбец | 25% | 十神 между дневными стволами + отношение дневных ветвей (супруг-дворец) |
| Взаимодополнение 五行 | 15% | парные слабые/пустые стихии покрываются партнёром |
| Найнь (纳音) | 10% | годовые найнь: тот же/порождение — плюс, столкновение — минус |

Интервалы:

| Балл | Категория | Тон ответа |
|---|---|---|
| 90–100 | 天作之合 «Союз, созданный небом» | радость + «не расслабляться» |
| 75–89 | 佳偶天成 «Прекрасная пара» | позитив + советы по укреплению |
| 60–74 | 尚可配对 «Достойное сочетание» | нейтрально-тёплый, зоны роста |
| 45–59 | 需要用心 «Требует усилий» | честно про трения, без страха |
| 30–44 | 有缘无分 «Мелкая карма» | мягко: «непросто, но выбор за вами» |
| 0–29 | 不建议强求 «Не стоит настаивать» | деликатно, фокус на самостоятельных смыслах |

**Всегда**: балл — инструмент, не приговор; любой диапазон заканчивается
советом по «развитию», а не вердиктом.

## 4. 十神 между дневными стволами (ключ 25%)

| Отношение A→B | Смысл для пары |
|---|---|
| 正官 / 正财 | «традиционная пара», стабильное притяжение |
| 正印 / 食神 | забота и поддержка, «тепло» |
| 比肩 | дружба-равенство |
| 伤官 / 七杀 | страсть + трения, нужен такт |
| 劫财 / 偏财 | притяжение с соревновательностью |
| 偏印 | опека с давлением |

Дневная ветвь = «дворец супруга»: её 六合/三合 с ветвью партнёра — очень
хороший знак; 冲 — горячая динамика; 害/刑 — накопительные трения.

## 5. Уровень 3: дворец супруга 紫微 (кратко)

Если полные движки недоступны, используй упрощённый портрет по дневной ветви
(из taohua-luck.md: 日支 → характер спутника):

子 — смышлёный, общительный; 丑 — надёжный, основательный; 寅 — смелый,
инициатор; 卯 — мягкий, артистичный; 辰 — волевой, статусный; 巳 — глубокий,
наблюдательный; 午 — яркий, энергичный; 未 — добрый, семейный; 申 — гибкий,
с юмором; 酉 — эстет, внимательный к деталям; 戌 — верный, ответственный;
亥 — великодушный, мудрый.

主星-портреты 紫微 (если у пользователя есть готовая карта): 紫微 — «сильный
партнёр», 天府 — стабильность, 太阴 — нежность/романтика, 贪狼 — магнетизм и
много ухажёров, 七杀 — яркая динамика, 破军 — «переписать жизнь», 巨门 —
потребность в глубоком разговоре, 天同 — покой и уют. Полные таблицы —
`references/ziwei-marriage.md` репозитория yinyuan-skills.

## 6. 桃花 (цветение персика): когда и где

**Персональный 桃花位** по годовой ветви: 寅午戌 → 卯 (Восток); 申子辰 → 酉 (Запад);
巳酉丑 → 午 (Юг); 亥卯未 → 子 (Север). Год с этой ветвью = год активной 桃花.

Типы: 正桃花 (серьёзные знакомства), 偏桃花 (лёгкие романы), 桃花劫 (расходы/
потери из-за отношений), 桃花煞 (обман/конфликты). Язык: предупреждение без
запугивания, всегда + «что делать».

**Сигналы «правильного момента»** (正缘): год идёт по личному 桃花位; годовой
ствол образует 五合 с дневным стволом; год «встряхивает» дворец супруга
(冲 дневной ветви) — перемены в статусе отношений.

## 7. Формат ответа по совместимости

1. Данные обоих (даты, ветви года/дня) — коротко.
2. Зодиак-уровень: категория + одна фраза-образ.
3. Балльный уровень: таблица измерений → итоговый балл + категория.
4. Сильные стороны пары (2–3 пункта), зоны внимания (1–2 пункта).
5. Конкретные советы по общению/ритму (без «амулетов»).
6. Дисклеймер: развлекательно-познавательный анализ, решение — за людьми.
